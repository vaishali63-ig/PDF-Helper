# PDF HELPER

A simple Clint side Fast Pdf Helper tool buoild with reactjs. It allows you to perform common pdf operations

## Tools
- **Image To PDF:** Converts images into pdf
- **PDF to Image:** Converts PDF into images
- **Merge Two PDF:** Merging 2 pdf files

## TechStack
- React
- Tailwind (css)
- vite

## Packages used
- jspdf
- pdf-lib
- pdfjs-dist
- react-router
- tailwindcss

---
Used jspdf for image to pdf conversion, pdf-lib for merge pdf files, pdfjs-dist for pdf to image conversion, tailwindcss for styling and react-router for page routes.
---

## How To Run Locally

Clone This Repository:
```bash
git clone https://github.com/vaishali63-ig/PDF-Helper.git
```
Run Project:

```bash
cd PDF-Helper
npm install
npm run dev
```
